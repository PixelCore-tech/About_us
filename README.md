### 🚀 Jak uruchomić

1. Sklonuj repozytorium:
```bash
git clone https://github.com
```

2. Wejdź do katalogu projektu:
```bash
cd NAZWA_REPO
```

3. Zainstaluj zależności:
```bash
npm install
```

4. Uruchom projekt w trybie deweloperskim:
```bash
npm run dev
```
